## ⚡ 60-Second Executive Summary

High-end streetwear brands like **Represent Clo** face extreme traffic spikes during limited collection drops (e.g., *Owners Club*, *Initial*). Standard Shopify themes often suffer from checkout friction, opaque shipping costs disclosed late in the funnel, and high layout shift—leading to cart abandonment during high-velocity launches.

This repository is an ultra-fast, edge-rendered **Luxury Streetwear Flagship Sandbox** engineered for drop-based D2C velocity:
1. **Sub-second LCP (`<1.4s`)** via Next.js Server Components and modern Tailwind layout structuring.
2. **Upfront Zero-Cost Shipping Guarantee** dynamically calculated in the interactive drawer prior to checkout.
3. **Ergonomic Size Matrix & Drawer Cart** with strict `≥48x48px` tap targets for high-pressure mobile drops.
4. **Editorial Brutalist Visual Taxonomy** pairing British streetwear pacing with technical HUD telemetry.

## 🏛️ Architecture & Tech Stack

- **Framework:** Next.js 14 (App Router) + React 18
- **Language:** TypeScript with strict type definitions
- **Styling:** Tailwind CSS with custom editorial dark tokens (`#0A0A0A` obsidian canvas)
- **Icons:** Lucide React
- **Deployment:** Render Web Service (`render.yaml` infrastructure-as-code)

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/billzzzifj/ext-represent-clo-sandbox.git

# Enter project root
cd ext-represent-clo-sandbox

# Install dependencies
npm install

# Launch development server
npm run dev
# Access local preview at http://localhost:3000
```
